# Weather Dashboard

**Live Demo:**  
https://vital-7-vital.github.io/Weather-Dashboard/

## Description

A real-time weather dashboard built using HTML, CSS, and JavaScript. It fetches weather data using the OpenWeather API and stores search history using Local Storage.

## Features

- 🌤 Search weather by city
- 🕒 Live date & time
- 📍 Weather icon and description
- 💾 Search history using Local Storage
- 🗑 Clear History button

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeather API
- Local Storage

## How to Run

1. Clone this repository.
2. Open `weather.html` in your browser.
